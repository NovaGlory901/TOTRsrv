People asking to join

When this is on, the TOTR apps on your network can find this server and send a join request. Nothing is created until you approve: approving makes a one-time invite that only that app can open, so they still choose their own username and password. The "install" code names one copy of the app: the same code on a later request means the same copy asked again. What the app says about the person's other server is only what the app reported, not proof.
